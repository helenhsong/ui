# Default system

Use the exported components from `@helenhsong/ui` before creating equivalents.
The component foundation is the current, unmodified `base-nova` shadcn style
with Base UI behavior and CSS-variable tokens from `src/index.css`.

Keep shadcn's component classes, Tailwind spacing scale, and radius mapping as
the defaults. In particular, `--radius` remains shadcn's `0.625rem` base and
the derived `--radius-*` values remain those generated by shadcn. Do not apply
base spacing or corner-radius values to the default system. Base-specific styles
may remain as a separate reference or system, but they do not override these
default primitives.

All registry primitives, the reusable Data Table, all documented Date Picker
variants, the Typeset wrapper, and the ten area-chart examples are public
exports. The full Typeset rules are included in the package stylesheet. The
namespaced sources in `examples/blocks` are copyable application patterns, not
package exports.

For standalone prototypes, import only the components the product needs and
apply this system's tokens. Do not include `ProjectHeader`; it is shared
portfolio chrome reserved for the `helen-build` workflow.

Keep product-specific layout and visual experimentation inside the consuming
project. Promote a pattern into this repository only after it is reused or is
intentionally part of the system.
